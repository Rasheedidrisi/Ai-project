# Design System

## Visual principles
- Warm editorial palette with ivory, forest green, and terracotta accents.
- Strong contrast for readability and focus.
- Minimal shadows and crisp borders instead of heavy glassmorphism.
- Responsive desktop-first but mobile-adaptive structure.

## Color tokens
- Paper: #F7F5EF
- Charcoal: #252820
- Forest: #315B45
- Sage: #DCE7D9
- Terracotta: #C96F4A
- Muted: #77796F

## UI patterns
- Sectioned cards for notes, summary, quiz, and flashcards.
- Clear action buttons with primary/secondary states.
- Consistent form controls using rounded corners and subtle focus rings.
